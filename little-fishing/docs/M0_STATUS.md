# 开发状态

更新时间：2026-08-20

## M0：桌面技术原型（已完成）

- React/TypeScript 主窗口，可开始、停止并显示绝对结束时间。
- 透明置顶浮标窗口，支持点击、右键菜单、拖动和状态提示。
- 紧凑状态面板，可跟随浮标所在显示器定位并限制在屏幕边界内。
- Rust 后台调度、窗口间状态同步、桌面通知、系统托盘和单实例运行。
- 主窗口关闭后隐藏；明确退出时结束应用。
- 已完成 Windows 桌面实机运行与浮标对齐验收。

## M1：持久化与钓鱼规则（进行中）

本轮已完成：

- 接入本地 SQLite，数据库位于系统应用数据目录。
- 使用 WAL 模式保存当前回合状态、结束时间、回合数、鱼饵配方名、最近结果和状态版本。
- 开始、停止、进入结算、完成结算和退出应用时都会保存状态。
- 应用重新启动时恢复上一轮；离线期间无论多长，只结算一次，然后从当前时间开始下一轮。
- 增加 SQLite 往返读写测试和离线单次结算测试。
- 将固定 7.5 分钟替换为 30 秒至 2 小时的分段概率：
  - 30 秒～5 分钟：1.5%
  - 5～15 分钟：34%
  - 15～30 分钟：34%
  - 30～45 分钟：20%
  - 45～60 分钟：9%
  - 60～120 分钟：1.5%
- 所有等待时长、结束时间和过程事件均精确到 30 秒。
- 每轮开始时一次性生成结束时间和过程事件，刷新窗口不会重新随机。
- 等待时长只影响过程事件数量，不影响后续鱼种判断。
- 增加环境、水面、钓组、动物、趣味插曲五类过程事件，每类 30 条。
- 60 条描述作为固定数据写入 SQLite，回合生成器从数据库载入事件池。
- 旧版 SQLite 数据库可自动增加新字段，无需清空存档。
- 增加味道浓烈度、色彩鲜艳度、甜、酸、咸五维鱼饵模型，所有维度限制为 0～1。
- 增加 8 种基础饵料和按百分比加权的默认配方“综合试钓饵”。
- 增加 10 种淡水鱼及固定元/公斤价格，来源记录见 `FISH_DATA_SOURCES.md`。
- 每种鱼每天按电脑本地日期生成一组隐藏五维偏好；同一天重复启动不会变化。
- 使用归一化五维距离计算相似度；低于 0.42 的鱼完全不会进入候选池。
- 相似度通过门槛后仍只提供 8%～55% 的中鱼概率，没有保底。
- 中鱼时生成鱼种、长度、重量、价值和过程描述；不中鱼时生成原因描述。
- 中鱼与不中鱼描述各 30 条，并与回合结果一起写入 SQLite。
- 增加鱼饵配方页，可从 8 种基础成分中自由组合任意正数份额，保存时按总量自动归一化。
- 钓鱼进行中锁定配方编辑；停止后保存的配方从下一次抛竿开始生效，并写入 SQLite。
- 增加鱼类记录页，始终展示全部鱼种、固定价格、累计钓获、最大长度、最大重量和最近特征描述。
- 每种鱼配有独立配色的像素风图标；未钓获鱼种不显示任何隐藏偏好信息。
- 自定义配方、选中配方编号和鱼类个人记录均兼容旧版存档迁移。
- 增加详细钓鱼日志，按回合保存开始/结束时间、等待时长、鱼饵、过程事件和最终结果。
- 日志默认展示最近 100 竿，单次最多读取 200 竿；旧回合也可继续显示，只是没有历史过程事件。
- 中鱼后进入不限数量的待处理鱼获队列，不阻塞下一轮自动抛竿。
- 增加“吃掉 / 卖掉”操作；每条鱼只能处理一次，数据库事务避免重复入账。
- 吃掉时随机增加鱼重 35%～80% 的体重，初始体重为 60 kg；增长值不会超过鱼重的 80%。
- 卖掉时按该条鱼结算时已经固定的价值增加金钱；当前不设置商店。
- 日志页展示当前体重、金钱、待处理数量以及累计吃掉/卖出数量，并随回合结算自动刷新。
- 回合结束通知现在直接显示本竿真实结果，而不是只提示“可以查看结果”。
- 增加设置页，统一管理结果通知、桌面浮标显示、浮标置顶、界面主题和减少动态效果。
- 设置保存在本地 SQLite，修改后同步到主窗口、浮标与紧凑状态面板，默认值保持旧版行为。
- 增加 Windows 开机启动；启用后登录系统时仅显示浮标，不主动弹出主窗口。
- 托盘手动显示或隐藏浮标时会同步更新设置，避免界面状态与实际窗口不一致。
- 界面主题支持跟随系统、固定浅色和固定深色；减少动态效果同时覆盖系统偏好与游戏内选项。
- 当前回合新增“已通知过程事件”持久化字段，旧数据库会自动补齐为空列表。
- 环境、水面、钓组三类过程事件会在计划时间发送对应标题的桌面通知。
- 事件在发送通知前先写入已通知集合；应用重启恢复后不会重复提醒同一事件。
- 通知关闭时事件仍按时记为已发生，之后重新开启不会集中补发旧消息。
- 回合结算优先于过期过程通知，避免电脑休眠恢复后在最终结果前连续弹出旧事件。
- 完成 Windows x64 release 编译和 NSIS 安装包生成。
- 发布版冒烟测试发现并修复设置状态注册竞态；修复后安装版可稳定后台启动。
- 完成独立目录安装、运行、关闭和静默卸载测试，安装目录、卸载项和开机启动项均无残留。
- 进行中回合改为仅显示正向累计的已垂钓时间，不再展示倒计时、计划等待或预计结束时间。
- 鱼类资料扩展为 40 种，鱼饵成分扩展为 24 种；现有 SQLite 存档会在启动时自动补齐新条目。
- 鱼饵属性从所有玩家界面及前端 IPC 返回值中移除，成分比例仍可自由配置。
- 桌面浮标增加四层椭圆水波并扩大透明窗口，release 版实机截图确认浮标居中且无错位。

- 移除系统通知与 `notify-rust` 依赖，避免 Windows 使用 PowerShell 兜底弹出提醒。
- 完成初始策划对齐检查：每竿从 30 条随机开场状态文案中抽取；过程事件扩展为 5 类共 150 条并提高长回合事件密度。
- 钓组事件加入挂底、断线、缠线、掉饵和换钩等真实状况；趣味插曲约占 20%，事件仍不改变结束时间、鱼种或中鱼概率。
