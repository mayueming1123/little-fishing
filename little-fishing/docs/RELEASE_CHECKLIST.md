## 构建期间发现并修复

首次 release 冒烟测试发现：生产前端可能在 Tauri `setup` 完成前调用设置命令，导致 `SettingsState` 尚未注册而崩溃。设置状态现已提前注册，数据库加载完成后再替换默认值；重新构建后启动测试通过。

## 发布前遗留

- 安装包尚未进行 Authenticode 数字签名，Windows 可能显示“未知发布者”。公开分发前建议购买或配置代码签名证书。
- 应用标识 `com.xiaoxiaodiaoyu.app` 会触发 Tauri 的 macOS 命名提示，但不影响 Windows。暂不修改，以免改变现有 Windows 应用数据目录并造成存档断开。
- 当前版本没有自动更新渠道；新版本仍需重新下载安装包。

## 重建命令

在已经加载 Visual Studio x64 开发环境、Rust 和 Node.js 的终端中执行：

```powershell
npm.cmd run tauri build
```

构建完成后应重新计算安装包 SHA-256；任何代码变化都会使本文件中的哈希失效。
